# Agapis Lapis: LQG

This app is made for a friend of mine. The name **Agapis Lapis** comes from a combination of the words: _agápis_, which is the Greek word for love when combined with another word. An example of this would be _molývi agápis_, which just means love pencil. This brings us to _lapis_, which is just the Tagalog for a pencil.

## Feature List

| Feature | Description |
| ------- | ----------- |
| **Love Quotes Generator** | You can get love quotes from three sources, two of which requires an internet connection. |
| **Magic Eight Ball** | An eight ball that just gives you vague answers to whatever questions you may have. |
